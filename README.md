# Ariel Movies 🍿

אפליקציית RTL ניידת לקטלוג סרטים וסדרות, עם חיפוש, קטגוריות, סדרות/עונות/פרקים, דפי פרטים, נגן פנימי וממשק ניהול מאובטח בצד השרת.

## פריסה ב-Render

- Build command: ריק
- Start command: `npm start`
- Environment:
  - `ADMIN_PASSWORD` - סיסמת המנהל
  - `SESSION_SECRET` - מחרוזת אקראית ארוכה
  - `GITHUB_TOKEN` - Fine-grained token עם Contents read/write ל-repo
  - `GITHUB_REPO` - `boherbatov/zovex-flow`
